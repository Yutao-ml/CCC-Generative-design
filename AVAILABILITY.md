# Availability statements

Replace [SHARED_ARCHIVE_DOI] with the real DOI of this version. These statements describe the deposited resources and runnable examples.

## Data availability

Carbon-element characterization maps, saved image subsets from AR, VAE, diffusion, GAN and DME-GAN, and retained structural and physical-response data are available at [SHARED_ARCHIVE_DOI]. The archive includes 32 characterization maps, 20 generated fields each for AR, VAE, diffusion and GAN, 500 DME-GAN fields, 302 response records and a 300-record structure-response table, with settings, units and source indices.

## Code availability

Code for inference with the selected DME-GAN checkpoint, per-image morphology analysis and screening of retained response records, together with the corresponding generator weights, is available in the same archive at [SHARED_ARCHIVE_DOI]. The repository documents its installation, inputs and outputs. Full training, checkpoint selection, closed-loop optimization and finite-element re-solving are outside this example release.
